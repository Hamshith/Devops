# Exercise 9

## Ensure Jenkins Is Running

1. Open a browser.
2. Navigate to `http://localhost:8080`, or use the URL for your Jenkins installation.
3. Log in with your Jenkins credentials.

Ensure Jenkins is running before continuing.

## Create the following files :

1. app.py
2. requirements.txt
3. test_app.py
4. Jeckinsfile

Have the code in all of these files as in the directory

Push the files to github

## Pipeline configuration : 

1. Click on New Item
2. Give a suitable name for the item and select pipeline, click OK
3. Click on the pipeline option in the left pane 
4. Under definition select Pipeline script from SCM
5. Under SCM select Git
6. Add git repo link and configure the branch it refers to
7. Give the path of the Jenkinsfile the buid should refer to
